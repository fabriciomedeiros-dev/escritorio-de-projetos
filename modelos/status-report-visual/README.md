# Modelo visual de Status Report de Projeto

Use este modelo para apresentar situação executiva, indicadores, funcionalidades com datas previstas e realizadas, fluxo de conclusão, próximo marco e próximos passos.

## Regras de preenchimento

- substituir todos os campos entre colchetes;
- manter no máximo três indicadores principais;
- listar uma linha por funcionalidade;
- usar a data de validação ou aceite como data realizada;
- usar `—` quando a funcionalidade ainda não possuir data realizada;
- manter melhorias futuras separadas do escopo que está sendo aprovado;
- ajustar as etapas do fluxo sem perder a sequência entre implementação, validação, aprovação, implantação e melhorias.

O arquivo `index.html` é a referência visual reutilizável. O modelo textual canônico está em `../relatorio-status.md`.

Execute `npm run build` para gerar a versão estática em `dist/`.
