## Organização

- arquivos editáveis devem ser mantidos neste diretório quando o formato permitir versionamento no repositório;
- protótipos hospedados em ferramenta externa devem ter o link registrado na tabela acima;
- exportações usadas para apresentação devem ficar em `exportacoes/`;
- o nome recomendado para uma exportação é `sac-prototipo-AAAA-MM-DD-versao.ext`;
- após cada validação, registrar a versão apresentada, a decisão e as pendências em `../../decisoes.md` e `../../historico.md`.

## Critério para considerar o protótipo validado

O protótipo somente será considerado validado após o aceite de Danielle Moitas e o registro das alterações ou ressalvas resultantes da reunião.
