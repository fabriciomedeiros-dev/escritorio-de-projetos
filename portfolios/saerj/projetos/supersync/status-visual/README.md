# Status visual — SuperSync

Painel executivo vinculado ao projeto SuperSync no Escritório de Projetos. A fonte gerencial canônica é o [relatório de status de 24/09/2026](../relatorio-status-2026-09-24.md); esta pasta mantém sua representação visual e os arquivos necessários para publicá-la.

**[Abrir o painel visual](dist/index.html)**

## Uso na documentação

- use o link acima ou abra `dist/index.html` para visualizar a versão estática local;
- atualize primeiro o relatório canônico e, em seguida, reflita as alterações em `index.html`;
- use a data de validação ou aceite como data realizada;
- mantenha melhorias futuras separadas do escopo em aprovação;
- registre divergências entre confirmação funcional e evidência técnica.

Execute `npm run build` para regenerar `dist/index.html`.
