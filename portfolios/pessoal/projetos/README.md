# Projetos pessoais

**Navegação:** [Início](../../../README.md) · [Portfólio pessoal](../portfolio.md) · [Modelos](../../../modelos/README.md) · [Conselho](../../../conselho/README.md)

Cada subpasta representa a memória gerencial de um projeto pessoal.

Crie novos projetos em `portfolios/pessoal/projetos/<nome-do-projeto>/` e copie os arquivos correspondentes de `modelos/`.

Todo `projeto.md` deve declarar o portfólio `pessoal` e possuir um identificador iniciado por `PESS-`.
